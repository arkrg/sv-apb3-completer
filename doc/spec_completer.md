# 검증용 APB4 slave RTL 명세

## 1. 목적과 범위

- APB3 agent(Master)를 시험하기 위한 **시험 도구**인 일반 RTL 모듈
- APB3 기본 신호(PSEL, PENABLE, PWRITE, PADDR, PWDATA, PRDATA, PREADY, PSLVERR)와 클럭/리셋만 사용

## 2. 확정 사항 요약

| 항목            | 결정                                                                           |
| --------------- | ------------------------------------------------------------------------------ |
| PREADY          | 모드 1(항상 1)과 모드 2(의사난수 지연)를 모듈 파라미터로 선택                  |
| 지연(모드 2)    | 전송마다 0~3 사이클, 최대 지연은 모듈 파라미터, 의사난수는 시드 고정           |
| 메모리          | 16 word (0x00~0x3C), 워드 접근                                                 |
| 리셋            | PRESETn(active-low), 리셋 시 16칸 전부 0x01CE_B007                             |
| PSLVERR         | 주소가 0x40 이상이면 1, 0x00~0x3C이면 0                                        |
| 범위 밖 read    | PRDATA = 0x05AD_D00D                                                           |
| 범위 밖 write   | 저장하지 않음 (배열을 건드리지 않음)                                           |
| 비access 구간   | PRDATA = 0, PSLVERR = 0                                                        |
| 주소 하위 2비트 | RTL은 무시, 항상 32bit 워드 전체 접근. 하위 2비트가 0이 아닌 주소는 SVA가 막음 |
| 포트 폭         | PADDR, PWDATA, PRDATA 모두 32bit                                               |

## 3. 포트 표

| 신호    | 방향   | 폭  | 설명                                                 |
| ------- | ------ | --- | ---------------------------------------------------- |
| PCLK    | input  | 1   | 클럭                                                 |
| PRESETn | input  | 1   | 비동기/동기 여부는 구현 시 안내, active-low          |
| PSEL    | input  | 1   | slave 선택                                           |
| PENABLE | input  | 1   | access phase 표시                                    |
| PWRITE  | input  | 1   | 1이면 write, 0이면 read                              |
| PADDR   | input  | 32  | 주소. 하위 2비트 무시, 사용 비트는 아래 주소 맵 참조 |
| PWDATA  | input  | 32  | write 데이터                                         |
| PRDATA  | output | 32  | read 데이터                                          |
| PREADY  | output | 1   | 응답 준비                                            |
| PSLVERR | output | 1   | 에러 응답                                            |

모듈 파라미터

| 파라미터       | 설명                                          |
| -------------- | --------------------------------------------- |
| 지연 모드 선택 | 모드 1(항상 PREADY=1) / 모드 2(의사난수 지연) |
| 최대 지연      | 모드 2에서 대기 사이클의 최댓값 (기본 3)      |

## 4. 주소 맵

| 주소 범위   | 동작                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| 0x00 ~ 0x3C | mem[PADDR[5:2]] 접근, PSLVERR = 0                                       |
| 0x40 이상   | 에러 영역. PSLVERR = 1, read는 PRDATA = 0x05AD_D00D, write는 저장 안 함 |

- 범위 판정은 PADDR[31:6]이 0인지로 한다 (0이면 범위 안).
- 아직 write하지 않은 칸을 read하면 PRDATA = 0x01CE_B007, PSLVERR = 0 (정상 전송).

## 5. 블록도

```
            +-----------------------------------------------------+
            |                    apb_slave                        |
            |                                                     |
 PADDR ---->|--> [주소 디코딩] --+--> 범위 안 : word index         |
            |   (범위 판정)      |    범위 밖 : 에러 플래그        |
            |                    |                                |
 PSEL    -->|--> [access 판정] --+--> setup/access/응답 사이클     |
 PENABLE -->|                    |                                |
            |                    v                                |
            |   [PREADY 제어] <-- 모드 선택(파라미터)             |
            |   모드1: 항상 1                                     |
            |   모드2: LFSR 카운터 (전송마다 새 값)      |
            |                    |                                |
 PWRITE -->|--> [메모리 배열 16 x 32bit] <-- 응답 사이클에서 write|
 PWDATA -->|         |  (리셋 시 전부 0x01CE_B007)                |
            |         v                                           |
            |   [응답 출력] --> PRDATA, PSLVERR (응답 사이클만 값) |
            +-----------------------------------------------------+
                         PREADY <-- [PREADY 제어]
```

## 6. 동작 규칙

### 6.1 전송 구분

- setup phase: PSEL=1, PENABLE=0
- access phase: PSEL=1, PENABLE=1
- 응답 사이클: access phase 중 PREADY=1인 사이클 (전송이 끝나는 사이클)

### 6.2 write

- 응답 사이클에서, 주소가 범위 안이면 mem[PADDR[5:2]] <= PWDATA.
- 주소가 범위 밖이면 저장하지 않고 PSLVERR=1.

### 6.3 read

- 응답 사이클에서 범위 안이면 PRDATA = mem[PADDR[5:2]], PSLVERR = 0.
- 범위 밖이면 PRDATA = 0x05AD_D00D, PSLVERR = 1.

### 6.4 PREADY

- 모드 1: PREADY는 리셋 중과 비access 구간을 포함해 항상 1. access phase는 항상 1사이클로 끝난다.
- 모드 2: 비access 구간에서 PREADY=0. access phase에서 N사이클(0~3, 전송마다 의사난수) 대기한 뒤 PREADY=1.
  - 다음 전송의 지연값은 전송이 끝날 때 새로 정한다. back-to-back에서도 매 전송 새 지연이 적용되어야 한다.

### 6.5 응답 신호 값 (비access 구간)

- PSEL=0 또는 PENABLE=0이면 PRDATA = 0, PSLVERR = 0. 리셋 중에도 같다.
- (제안, 확인 필요) 모드 2에서 PREADY=0인 대기 사이클에도 PRDATA, PSLVERR는 0으로 두어, 값이 응답 사이클에만 나타나게 한다.

### 6.6 리셋

- PRESETn=0이면 mem 16칸을 전부 0x01CE_B007로 초기화한다.
- 리셋 중 PRDATA = 0, PSLVERR = 0. PREADY는 모드 1이면 1, 모드 2이면 0.

## 7. 파형

### 7.1 모드 1, write (지연 없음, 범위 안)

```
cycle    :  0   1   2   3   4
PCLK     : _|‾|_|‾|_|‾|_|‾|_|‾|_
PSEL     : ____|‾‾‾‾‾‾‾‾|________
PENABLE  : ________|‾‾‾‾|________
PWRITE   : ____|‾‾‾‾‾‾‾‾|________
PADDR    : ----< 0x08   >--------
PWDATA   : ----< data   >--------
PREADY   : ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾  (항상 1)
PSLVERR  : ____________________   (0)
         setup(1) access(2) -> cycle 2 끝에서 mem[2] <= data
```

### 7.2 모드 2, read, 지연 2 (범위 안)

```
cycle    :  0   1   2   3   4   5
PSEL     : ____|‾‾‾‾‾‾‾‾‾‾‾‾‾‾|____
PENABLE  : ________|‾‾‾‾‾‾‾‾‾‾|____
PWRITE   : ________________________ (0)
PADDR    : ----< 0x08           >----
PREADY   : ______________|‾‾‾‾|______   (access 2사이클 대기 후 1)
PRDATA   : ______________<mem[2]>_____   (응답 사이클에만 값, 그 외 0)
PSLVERR  : ______________________      (0)
```

### 7.3 모드 2, read, 범위 밖 (지연 1)

```
cycle    :  0   1   2   3
PSEL     : ____|‾‾‾‾‾‾‾‾‾‾|____
PENABLE  : ________|‾‾‾‾‾‾|____
PADDR    : ----< 0x40     >----
PREADY   : ____________|‾‾|______   (1사이클 대기 후 1)
PRDATA   : ____________<05ADD00D>   (응답 사이클에만)
PSLVERR  : ____________|‾‾|______   (응답 사이클에서 1)
```

### 7.4 back-to-back, 모드 1 (write 후 read)

```
cycle    :  0   1   2   3   4
PSEL     : ____|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|____
PENABLE  : ________|‾‾‾‾|____|‾‾‾‾|__ ... (다음 setup이 바로 이어짐)
```

access phase 종료 직후 사이클이 곧바로 다음 전송의 setup phase이며(PSEL 유지, PENABLE=0), slave는 이 전송에도 새로 응답해야 한다.
